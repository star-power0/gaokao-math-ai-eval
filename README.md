# 2026年高考数学 AI 模型打分评测系统 (Gaokao Math AI Eval)

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Deploy Version](https://img.shields.io/badge/Deploy%20Version-v1.2.4-blue)](https://github.com/star-power0/gaokao-math-ai-eval)
[![Speed Ranking](https://img.shields.io/badge/Speed%20Ranking-Gemini%20%3E%20Claude-brightgreen)](#模型运行与速度测试)

这是一个用于评测与对比各大主流大语言模型在 **2026年高考数学试卷** 实际作答表现的交互式可视化仪表盘系统。本系统结合真实的官方标准参考答案及评分建议，对 9 个模型进行了精细化步骤打分、扣分点分析，并支持双模型逐题横向对比分析。

---

## 🌟 核心特色 & 关键说明

### 1. 真实运行与客观打分
> [!IMPORTANT]
> 本项目所有模型的得分、扣分明细及答卷内容，均基于**实际跑出来的真实数据**（非模拟、非虚构）。所有作答均使用 2026 年高考数学试卷进行实测。

### 2. 模型后缀及环境说明
在评测中，针对特定环境运行的模型，我们采用了以下命名后缀：
* **`work`**：代表 **WorkBuddy** 平台（例如 `GLM 5.1 (work)`，即在该平台上实际跑出的 GLM 5.1 模型作答结果）。
* **`trae`**：代表字节跳动旗下的 **Trae IDE** 内置模型（例如 `GLM 5.1 (Trae)`，即在 Trae IDE 实际跑出的 GLM 5.1 模型作答结果）。

### 3. 模型运行速度排行 (Speed Benchmark)
在实际测试与生成作答的过程中，各大模型表现出了不同的响应与推理速度：
1. **Gemini 最快**：在所有参测模型中，Gemini 的推理和响应速度拔得头筹。
2. **Claude 其次**：Claude 紧随其后，速度同样处于第一梯队。
3. **其他模型**：其余模型推理速度慢于 Gemini 和 Claude。

## 🛠️ 技术栈与优化特性

本项目虽然是无后端单页应用（SPA），但为了呈现极致的用户体验与精美的视觉设计，我们实现了以下技术特性：

* **现代化视觉设计 (UI/UX)**：采用现代暗色/亮色双主题设计，支持一键切换。使用毛玻璃（Glassmorphism）、微交互动画、柔和渐变色以及精心定制的 HSL 配色体系，营造出极其高端的数理专业质感。
* **零延迟缓存与背景渲染机制 (Zero-Lag Switch)**：
  - 针对大文本 Markdown 与复杂 LaTeX 数学公式渲染较慢的问题，我们在页面加载时，自动在后台利用 `setTimeout` 对所有模型答卷内容进行**异步背景预渲染**。
  - 将渲染后的 HTML 写入 `renderedContentCache` 缓存对象。在用户切换模型或对比题目时，**直接读取缓存**，瞬间呈现画面，实现“指哪打哪”的零卡顿丝滑体验。
* **高精度数学公式支持**：集成 **KaTeX** 作为 LaTeX 数理公式的排版引擎，无论是简单的代数式还是复杂的空间向量、矩阵推导，均能在毫秒级时间内渲染完毕，效果媲美 LaTeX 排版。
* **智能正则抽取系统 (extractQuestionSection)**：
  - 采用独创的带**负向先行断言（Negative Lookahead）**的正则表达式 `(?!\d)`，确保在抽取某一道题目（如“第 1 题”）时，不会误匹配到其他包含该数字前缀的题号（如“第 11-19 题”），从根本上杜绝了题目内容溢出或混入其他题目的 bug。
* **移动端响应式与多端自适应**：
  - 对手机等窄屏设备进行了深度适配，利用 CSS Grid 的 `minmax(0, 1fr)` 配合局部横向滚动，确保包含表格、超长公式及代码块的复杂主观题解答在任何视口宽度下均不会溢出或被异常截断。

## 📂 项目结构

```
评测网站/
├── index.html         # 评测系统主页面（含仪表盘、详情页、对比页结构）
├── style.css          # 全局样式文件（含主题变量、响应式布局、高级动效）
├── app.js             # 核心交互逻辑（渲染器、缓存控制器、正则表达式抽取）
├── data.js            # 编译后的评测数据源（含主报告及所有模型答卷内容）
├── compile_data.py    # 数据编译脚本（读取原始 md 文件并打包为 data.js）
└── README.md          # 本说明文档
```

在同级或上级目录中，包含原始的数据输入源：
```
答案/
├── 2026年高考数学AI模型打分报告.md     # 评测主报告 markdown
├── 2026年高考数学Gemini 3.5flash.md   # 各模型原始作答 md 文件
└── ... (其他模型的作答 markdown 文件)
```

## 🚀 本地开发与数据编译指南

### 1. 数据编译
如果你修改了 `答案/` 目录下的某位模型的答卷或主报告内容，你需要重新编译数据生成 `data.js`：

1. 确保已安装 Python 3 环境。
2. 在终端中切换到 `评测网站` 目录下：
   ```bash
   cd A:\GeminiWorkspace\评测网站
   ```
3. 运行编译脚本：
   ```bash
   python compile_data.py
   ```
4. 编译成功后，脚本会自动将最新数据打包并覆盖 `data.js`，控制台将输出：
   ```
   Success: data.js successfully compiled to A:\GeminiWorkspace\评测网站\data.js
   ```

### 2. 本地运行与浏览
直接在浏览器中打开 `index.html` 即可。
如需使用本地服务器启动，可运行以下命令之一：
* **Python**: `python -m http.server 8000`
* **Node.js (http-server)**: `npx http-server -p 8000`

随后在浏览器中访问 `http://localhost:8000` 即可。
